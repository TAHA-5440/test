Viewer Logic (reconstructed)

PK(module_imaios_code, contrast, sort_order, version)
stack = SELECT sort_order WHERE module=? AND contrast=? AND version=? ORDER BY sort_order
viewer pagination: 1..N contiguous (N == COUNT(*))
downloaded flag == 0 (all rows) → none cached
image URL pattern hypothesis: https://cdn.imaios.com/eanatomy/{module}/{contrast}/{sort_order}.jpg?version={version}
